# Random Task Generator

**Автор:** [Любицкая]

## Описание

Простое GUI-приложение для генерации случайных задач. Помогает выбрать занятие из предопределенного списка или добавить свое.

## Функционал

-   Генерация случайной задачи из списка.
-   Добавление собственных задач с проверкой на пустую строку.
-   Сохранение истории сгенерированных задач в файл `tasks.json`.
-   Фильтрация истории по типу задач (Учеба, Спорт, Работа).
-   Очистка истории.

## Технологии

-   Язык: Python 3.x
-   Библиотеки: `tkinter`, `random`, `json`

## Использование

1.  Установите Python (>= 3.7).
2.  Запустите файл `main.py`.

## Примеры использования / Тесты

1.  **Генерация:** Нажмите кнопку «Сгенерировать задачу». Внизу появится новая запись в истории.
2.  **Добавление:** Нажмите «Добавить свою задачу». Введите текст и тип (например, «уборка», тип «работа»). Задача добавится в общий пул.
3.  **Фильтрация:** Выберите фильтр «Спорт». В списке истории останутся только спортивные задачи.
4.  **Ошибка:** Попробуйте добавить пустую задачу — появится окно с ошибкой.
